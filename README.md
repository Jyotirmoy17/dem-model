# Distilled Explanation Model (DEM)

This package provides the implementation of the `DEM`, a hybrid "glass-box" machine learning model designed for high accuracy and full interpretability.

The DEM framework creates an explainable model by distilling the complex knowledge of a powerful Blacbox model into a simple, rule-based decision tree. This tree then provides clear explanation of the gap between the baseline and the Blackbox model, enabling us to explain the anomalies and the gap.
